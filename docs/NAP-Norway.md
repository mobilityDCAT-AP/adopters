## Access metadata

When looking at a dataset description, choose the "RDF" tab to see the metadata in machine readable form.

Note: While the NAP supports mobilityDCAT-AP, most of the entries follow [DCAT-AP-NO](https://informasjonsforvaltning.github.io/dcat-ap-no/#_abstract_in_english) (a Norwegian profile). 

## Harvest metadata

All metadata from the NAP can be harvested as an RDF/XML file, or via an API, [as described here](https://data.norge.no/en/datasets/766d57bf-6b45-347e-80fe-ddbb47f663f0/dataset-descriptions-in-transportportalno).
